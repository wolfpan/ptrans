隐私政策 / Privacy Policy

适用扩展：AI Web Translator (OpenAI Compatible)（Chrome Web Store 发布）
Applies to: AI Web Translator (OpenAI Compatible), published on the Chrome Web Store.
生效日期 / Effective date: 2026-11-12

1. 我们收集什么 / What we collect

我们不运营任何服务器，不收集、不存储任何用户数据。本扩展没有账号体系、没有统计埋点、没有广告。
We operate no servers and collect or store no user data. The extension has no accounts, no analytics and no advertising.

2. 数据如何流动 / How data flows

  • 本地设置：您填写的 API 地址、API Key、模型名称、目标语言、翻译风格等仅保存在您浏览器本地的 chrome.storage.local 中，不会发送给我们。
    Your settings (API base URL, API key, model, target language, style) are stored only in your browser's local chrome.storage.local and never sent to us.
  • 翻译请求：仅当您点击"翻译当前网页"时，扩展才读取当前页面的可见文本，并通过 HTTPS 直接发送到您自己配置的 OpenAI 兼容 API 地址（API Key 仅作为该请求的鉴权头）。页面文本不经过我们，我们也无法看到。
    Only when you click "Translate this page" does the extension read the page's visible text and send it over HTTPS directly to your own configured OpenAI-compatible API endpoint (your API key travels only as the authorization header of that request). Page text never passes through us.
  • 后台行为：未发起翻译时，扩展不读取、不上传任何页面内容，不跟踪浏览行为。
    When you do not trigger a translation, the extension reads nothing, uploads nothing and does not track browsing.

3. 数据保留与删除 / Retention & deletion

本地设置保留至您主动清空或卸载扩展；卸载即全部删除。已发送至您所配置 API 的文本，其保留期限由该 API 服务商的隐私政策约束，请自行查阅。
Local settings remain until you clear them or uninstall the extension; uninstalling deletes everything. Text sent to your configured API is governed by that provider's privacy policy.

4. 权限说明 / Permissions

  • <all_urls>：向您自定义的任意 API 域名发起翻译请求；在您发起翻译时读写当前页面文本。
  • storage：本地保存您的翻译设置。

<all_urls>: call your custom API endpoint on any domain and read/replace page text when you trigger translation. storage: persist your settings locally.
